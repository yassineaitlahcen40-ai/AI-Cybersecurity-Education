# AI Cybersecurity Education

An interactive educational website designed to help users understand
cybersecurity risks associated with Artificial Intelligence and learn
how AI systems, data, and users can be better protected.

## About the Project

This website was developed as part of the **CSci-18 group project**. The
main goal of the project is to make AI cybersecurity topics easier to
understand through a clear, accessible, and engaging web experience.

The platform introduces users to important risks affecting AI systems
and explains practical approaches to safer and more responsible AI use.

## Topics Covered

The educational content covers areas such as:

-   AI and cybersecurity risks
-   Prompt injection
-   AI system manipulation
-   Data breaches and secure data handling
-   AI hallucinations and misinformation
-   Fake or AI-generated content
-   Bias in AI systems
-   Input validation
-   Security and safety layers
-   Human oversight
-   Protecting AI systems and data

## Website Features

-   Modern and user-friendly interface
-   Educational content about AI cybersecurity
-   Interactive learning elements
-   Cybersecurity case studies and examples
-   Quiz-based learning
-   Clear navigation between topics
-   Responsive design for different screen sizes
-   Practical guidance for safer AI use

## Technologies Used

The website was built using:

-   **HTML5** --- website structure and content
-   **CSS3** --- styling, layout, responsiveness, and visual design
-   **JavaScript** --- interactivity and dynamic functionality

## Purpose

Artificial Intelligence is becoming increasingly integrated into
everyday technology, but it also introduces new cybersecurity
challenges. This project aims to increase awareness of these risks and
provide users with an accessible introduction to protecting AI systems
and using AI more safely.

The website is intended primarily as an educational resource rather than
a professional security product.

## Getting Started

To run the website locally:

1.  Download or clone this repository.
2.  Open the project folder.
3.  Open the main `index.html` file in a web browser.

No additional installation should be required for the standard HTML,
CSS, and JavaScript version of the website.
